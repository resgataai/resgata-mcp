# Resgata MCP

Servidor MCP (Model Context Protocol) oficial da [Resgata.ai](https://resgata.ai). Ele vai permitir que usuários autorizados consultem dados, peçam análises e executem operações de negócio da plataforma em linguagem natural, a partir do **Claude** (Claude Code, Claude.ai e Claude Desktop) e do **Codex**. O login usa a mesma conta do painel admin da Resgata.ai, por OAuth.

> **Estado: em construção.** O servidor ainda **não está no ar** e não há nada para instalar hoje. O guia de instalação (`INSTALAR.md`) e o catálogo de ferramentas entram aqui junto com o primeiro incremento.

## Para quem é

Para a equipe da Resgata.ai e para parceiros com conta no painel admin e papel liberado. Este repositório não contém credenciais. O acesso aos dados depende sempre do login e das permissões de cada usuário, conferidos no servidor a cada chamada.

## Ordem de entrega

1. Login OAuth pelo painel admin, consultas essenciais e comandos diretos por canal, com prévia e auditoria.
2. Atendimento com o Chatwoot e a Agente Rê, campanhas e cobrança.
3. Acompanhamentos, rotinas e central de execuções.
4. Diagnóstico de conversão, de custos e de provedores, atribuição e recomendações.
